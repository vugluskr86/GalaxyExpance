# BUGS — актуальный реестр дефектов

Дата сверки: **31 июля 2026 года**.

## Критические / блокирующие

### BUG-001 — scanner принимает только Tab

**Статус:** открыт.  
**Симптом:** в `/usr/bin/scanner.bin` переключение экранов по `Tab` работает, но `Esc`, стрелки, `Enter`, `D`, `R`, `S` не дают ожидаемого результата.  
**Риск:** графическую программу нельзя штатно закрыть и нельзя использовать основные действия UI.  
**Затронуто:** `examples/c/scanner.c`, `src/game/terminal.js`, `src/game/cpu.js`, `src/game/os.js`, C codegen и тестовая модель ввода.  
**Пробел тестов:** существующие тесты проверяют отдельные keycode и VM-трассы, но не воспроизводят реальный жизненный цикл браузерного события → canvas/focus → terminal queue → syscall → скомпилированный C handler → завершение процесса.

### BUG-002 — полный набор тестов не завершается за разумный лимит

**Статус:** открыт.  
`npm test` проходит большую часть набора, но во время аудита не завершился за 5 минут. Это затрудняет достоверную маркировку релиза и может указывать на зависающий тест или слишком дорогую bootstrap-группу.

## Подтверждённые падения тестов

### BUG-003 — balance override отклоняет тестовое значение

`test/balance-config.test.js`: `Invalid config economy.marketTargetBase`. Требуется синхронизировать диапазон валидатора, тест и фактические единицы параметра.

### BUG-004 — crt0/libc возвращает неверный status

`test/unix-libc.test.js`, сценарий `stage 4 libc links crt0 + main and exits with main status`: получено `1`, ожидалось `0`.

### BUG-005 — make не выполняет часть рецептов и зависимостей

Падают сценарии `test/unix-make-env.test.js`:

- выполнение рецепта через `sh`;
- обход отсутствующей зависимости через дочерний make;
- разбор полного системного Makefile без достижения лимита инструкций.

### BUG-006 — Makefile не покрывает scanner.bin из install manifest

`test/unix-make-env.test.js`: отсутствует цель `scanner.bin` для `/usr/bin/scanner.bin`.

## Ограничения, которые следует считать техническим долгом

- `sizeof(expr)` в C parser использует fallback, а не полную семантику.
- Оператор взятия адреса `&` отмечен в codegen как не реализованный.
- ABI C принимает максимум четыре регистровых аргумента в текущем codegen.
- `sysRename` имеет неполное тестовое покрытие (`test/vfs.test.js`).
- Документы старых ревизий содержали утверждения о прохождении scanner controls, не подтверждённые ручным запуском; они перенесены в `archive/`.
