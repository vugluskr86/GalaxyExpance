# Боковая панель и навигация

`SceneManager` хранит стек открытых сцен. Панель показывает этот путь как
кликабельные крошки; переход к предыдущей сцене выполняется через
`navigateTo(index)` и сохраняет её выбор, камеру и прочий контекст.

`panelSpec()` описывает только данные и действия текущей сцены. Общие
настройки изображения находятся в раскрываемом разделе «Настройки», поэтому
не смешиваются с управлением полётом, торговлей или экипировкой. Настройка
модулей корабля выполняется только в `OutfitScene`; сохранение мира и
балансировочная лаборатория доступны из настроек системной сцены.

Элементы действия поддерживают `disabled` и `reason`. Панель показывает
причину рядом с недоступным действием, а `SceneManager.actionResult()`
локализует причины отказа игровых API в toast. Числовые значения в UI следует
выводить через функции из `src/game/units.js`; `fmtNumber()` и форматтеры
единиц отображают `—` вместо `NaN`.
