# ROADMAP_CHECK — актуальное состояние работ

Дата сверки: **31 июля 2026 года**. Источники: исходники `src/`, PCOS в `system/unix/`, build-скрипты, примеры и тесты `test/`.

## Выполнено и подтверждено тестами

- [x] Процедурная генерация кластеров, галактик, систем, звёзд, планет и поверхностей.
- [x] Корабли, оборудование, инвентарь, масса, двигатели, оружие и повреждения систем.
- [x] Посадка/взлёт, сохранение положения и восстановление выброшенного груза.
- [x] Экономика станций, торговля, контракты, NPC-экономика и агенты.
- [x] Сохранения мира с миграцией части старых состояний.
- [x] Бортовой компьютер с CPU, RAM, GPU, накопителями, BIOS и терминалом.
- [x] PCVM с фиксированной таблицей из 134 opcode, protected mode v3 и syscall ABI.
- [x] Host assembler/linker, PCOB v2, статическая и динамическая линковка.
- [x] Self-hosted assembler2/linker2: bootstrap второго поколения проходит отдельные тесты.
- [x] PCOS: kernel, init, VFS/PCFS, процессы, пользователи, права, shell и набор Unix-подобных утилит.
- [x] C frontend: lexer, preprocessor, parser и codegen для используемого подмножества C.
- [x] Сборка `scanner.c` в `/usr/bin/scanner.bin`; оба графических экрана рисуются программой PCVM без вызова JS scanner-сцены.
- [x] Локализация RU/EN и автоматическая проверка строк сцен.
- [x] Сетевые модели ARP/IP/UDP, DHCP, switch и буферы на уровне игровой симуляции.

## В процессе / частично реализовано

- [~] **Scanner на C:** графический UI и переключение `Tab` работают; остальные команды ввода в реальном UI не подтверждены и по ручному отчёту не работают.
- [~] **C-компилятор:** достаточен для части программ, но не является полным C89; `sizeof(expr)` и address-of в codegen отмечены как незавершённые, сложные выражения требуют регрессионной проверки.
- [~] **libc:** большая часть строковых, IO, malloc, printf, path/getopt функций тестируется, но тест возврата `main` через `crt0` падает.
- [~] **make внутри PCOS:** простая сборка hello проходит, однако разбор/выполнение рецептов, рекурсивные зависимости и полный системный Makefile имеют падения.
- [~] **Баланс-конфигурация:** инфраструктура и telemetry существуют, но один тест изменения `economy.marketTargetBase` падает на валидации.
- [~] **Исследование и зонды:** игровые системы и JS-сцена существуют, но нативная PCOS-программа scanner ещё не является полностью управляемой.
- [~] **Мобильная версия:** часть адаптации интерфейса есть, завершённость всех сцен и ввода не подтверждена.
- [~] **Производство/переработка/крафт:** отдельные сущности и планы есть, но замкнутый производственный цикл не подтверждён.
