# Pixel Cosmos

Процедурный пиксельный космос с четырьмя уровнями погружения и физикой в духе KSP. Вся вселенная — чистая функция одного зерна.

**Кластер галактик → Галактика → Звёздная система → Тело (планета/луна)**

Игрок стартует в случайной системе на орбите случайной планеты или спутника.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка в docs/
npm run deploy   # сборка и выкладка в GitHub Pages
```

## Орбитальная механика (KSP-подобная)

- **Патч-коники** — корабль интегрируется в системе отсчёта доминирующего тела.
  При пересечении SOI состояние конвертируется в раму нового тела.
- **FSD-круиз** — сверхбыстрое перемещение между телами с автоторможением.
  Выход из FSD сохраняет вектор скорости — гравитационный захват без циркуляризации.
- **Гомановский переход (H)** — два импульса между круговыми орбитами.
- **Манёвровые узлы (M)** — планирование delta-v в заданной точке орбиты
  с таймером (по умолчанию 20 сек).
- **Ручное пилотирование** — WASD (нос/prograde/retrograde),
  C (циркуляризация в текущей точке).
- **Предсказание траектории** — жёлтый пунктир на карте системы.

## Бортовой компьютер и консоль

- **Борткомпьютер** — слот `computer` в экипировке. МК-1 «Пролог» (32 КБ) стоит
  по умолчанию. Можно установить МК-2П «Алгол» (128 КБ). Программы хранятся
  в памяти компьютера, можно подобрать компьютер с предустановленным софтом.
- **Редактор программ** — кнопка «Программировать» на слоте компьютера
  в экипировке. Сохранение, загрузка, удаление `.bas`-файлов.
  Размер программы считается в байтах (UTF-8).
- **Консоль (`~`)** — игровая консоль, доступна с любого экрана.
  Легальные команды: `help`, `status`, `info`, `orbit <h>`, `circ`,
  `fsd <буква>`, `land`, `takeoff`, `speed <n>`.
  Читерские: `give <id> [q]`, `fuel <n>`, `refuel`.

## Игровой цикл

Выбрать звезду → FSD к выбранному (F) → корабль входит на орбиту →
Гоман к цели (H) / ручное пилотирование → выбрать планету → осмотреть → посадиться → панорама, заправка → взлёт.

## Ключевые контракты

- **Детерминизм.** Любой объект восстановим по коду. Порядок вызовов rng —
  часть контракта: `Galaxy.starInfo()` и `buildSystem()` читают один генератор.
- **LOD.** Далеко: пыль + маяки каталога. Ближе: посекторная генерация (LRU-кэш).
- **Сцена** — объект с update/draw/onTap/onHover/onWheel/status/panelSpec/primary/search.
- **Рендеринг** — Canvas 2D. Текст на отдельном слое (#labels, devicePixelRatio),
  пиксель-арт на #scene с image-rendering: pixelated.

## Отказ от WebGL

WebGL-миграция (попытка ускорить рендеринг планет на GPU) была откачена из-за
проблем с синхронизацией канвасов (parallax орбит и планет), потерей
пиксель-арт-текстур и нестабильностью на малом разрешении 420×420.
Рендеринг остаётся на проверенном Canvas 2D.
