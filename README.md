# Pixel Cosmos

Процедурный пиксельный космос с четырьмя уровнями погружения:

**Кластер галактик → Галактика → Звёздная система → Тело (планета/луна)**

Вся вселенная — чистая функция одного зерна. Ничего не хранится: сектора звёзд,
каталоги, системы и текстуры планет пересобираются детерминированно из хешей.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка в dist/
```

Открывать в VS Code как обычный Vite-проект.

## Архитектура

```
src/
  core/          примитивы, не знающие про космос
    rng.js         mulberry32 + целочисленные хеши (фундамент детерминизма)
    noise.js       value noise 3D + fbm
    color.js       палитры, дизеринг Байера, чёрное тело
    naming.js      генератор имён в духе Elite (диграфы)
    input.js       pan / tap / wheel → маршрутизация в активную сцену
  gen/           генераторы контента (без DOM-логики, кроме canvas-спрайтов)
    starclass.js   спектральные классы O–M + L (коричневые карлики)
    planet.js      текстуры и рендер планет (кольца, облака, кратеры), луны
    star.js        звёзды: грануляция, лимб, корона
    blackhole.js   ЧД: горизонт, фотонное кольцо, аккреционный диск
    galaxy.js      class Galaxy: поле плотности (спираль/шаровое/эллиптическая),
                   сектора с LRU-кэшем, каталог-маяки, квазары, ядро-ЧД, пыль
    cluster.js     class Cluster: верхний уровень, миниатюры галактик
    system.js      buildSystem: система из звезды галактики (общий rng со starInfo!)
  scenes/        стек сцен (каркас игры)
    manager.js     SceneManager: push/pop, крошки, маршрутизация
    cluster.js     ClusterScene
    galaxy.js      GalaxyScene (вращение, LOD, классификация, поиск)
    system.js      SystemScene (планеты, пояс, кометы; ЧД-режим с S-звёздами)
    body.js        BodyScene (крупный план с лунами)
  ui/
    panel.js       панель параметров: строится из panelSpec() активной сцены
    settings.js    глобальные настройки вида
  main.js        связывает всё: canvas, цикл, ввод, кнопки
```

## Ключевые контракты

- **Детерминизм.** Любой объект восстановим по коду: `GAL-07` → галактика,
  `NAV-0A3` → звезда каталога, `FLD-512-497-3` → звезда сектора (координаты
  зашиты в код, прыжок за O(1)), `QSO-2`, `SMBH-0`. Порядок вызовов rng —
  часть контракта: `Galaxy.starInfo()` и `buildSystem()` читают один генератор,
  поэтому карточка «планет: 4 · пояс» всегда совпадает с реальной системой.
- **LOD.** Далеко: пыль + ~тысяча маяков каталога. Ближе: посекторная
  генерация поля (LRU-кэш на 1000 секторов). Совсем близко: размеры по
  светимости, подписи.
- **Сцена** — объект с update/draw/onTap/status/panelSpec/primary/search.
  Добавить новый экран = новый класс + push в менеджер.
- **Текст** рисуется на отдельном чётком слое (#labels, devicePixelRatio),
  пиксель-арт — на #scene с image-rendering: pixelated.

## Игровой слой (src/game/)

- **ship.js** — корабль игрока и NPC («Торговец», «Патруль»…): полёт к цели с
  доворотом, выход на орбиту; NPC-мозг сам выбирает следующую планету.
- **player.js** — персистентное состояние поверх стека сцен: топливо,
  последняя звезда; стоимость гиперперехода = дистанция между звёздами / 25
  (между галактиками — фикс). Заправка при посадке.
- **stats.js** — характеристики планеты из зерна и инсоляции (L звезды /
  орбита): средняя температура (с парниковым эффектом по типу), состав и
  давление атмосферы, жидкости (вода / метановые озёра / расплав), недра
  (металлы и минералы с богатством залежей), растительность, гравитация,
  длина суток. Показываются в тултипе при наведении на планету/луну.
- **scenes/landing.js** — посадка: процедурная панорама поверхности.
  Небо — из атмосферы (без неё — чёрное со звёздами), положение и цвет солнца —
  из фазы вращения планеты (время суток идёт вживую), рельеф — из зерна
  (два хребта fbm, шероховатость по типу мира), море с бликом — если есть
  жидкость, ростки — если есть растительность, и восходы лун по их
  орбитальным углам с освещённой стороной к солнцу.

Игровой цикл: выбрать звезду → «Гиперпереход» (топливо) → выбрать планету →
«Лететь к выбранному» → корабль выходит на орбиту → «Посадка» → панорама,
заправка → «Взлёт».
