# План разработки генератора инопланетных цивилизаций и существ

## 1. Цель проекта

Создать генератор, который по одному `seed` формирует связанную инопланетную цивилизацию:

* тип жизни;
* среду обитания;
* морфологию существа;
* общество и культуру;
* технологии;
* название;
* краткий и расширенный лор;
* аватар существа;
* эмблему;
* флаг;
* цветовую палитру;
* визуальный стиль кораблей;
* структурированный JSON для сохранения в игре.

Система должна поддерживать два режима:

1. **Процедурный режим**

   * работает сразу;
   * не требует загрузки моделей;
   * полностью воспроизводим по `seed`;
   * подходит для слабых устройств.

2. **AI-режим**

   * локально улучшает лор;
   * локально улучшает процедурный портрет;
   * использует WebGPU или WebAssembly;
   * загружается только по запросу пользователя.

---

# 2. Основные принципы архитектуры

## 2.1. JSON является источником истины

Нейросеть не должна самостоятельно определять основные свойства цивилизации.

Сначала обычный код создаёт:

```json
{
  "life": {},
  "habitat": {},
  "morphology": {},
  "society": {},
  "technology": {},
  "history": {},
  "visualIdentity": {}
}
```

После этого:

* Canvas строит изображения по JSON;
* локальная языковая модель превращает факты в текст;
* image-to-image модель улучшает процедурный портрет.

## 2.2. Все результаты должны быть воспроизводимы

Один и тот же `seed` должен давать:

* одинаковый профиль цивилизации;
* одинаковую морфологию;
* одинаковую палитру;
* одинаковую эмблему;
* одинаковый базовый портрет;
* одинаковые исторические факты.

Текст нейросети может незначительно отличаться, поэтому рекомендуется:

* передавать отдельный seed генерации;
* использовать низкую температуру для энциклопедического текста;
* сохранять готовый текст в JSON после первой генерации.

## 2.3. Нейросеть не должна быть обязательной

При ошибке загрузки модели приложение должно автоматически использовать:

* шаблонный лор;
* процедурный портрет;
* процедурные названия;
* процедурные флаги и эмблемы.

# Этап 2. Реализовать детерминированный генератор профиля

## Задача

Создать полностью процедурный генератор фактов без использования AI.

## Порядок генерации

```text
Seed
→ тип жизни
→ совместимая среда
→ морфология
→ органы чувств
→ коммуникация
→ психология
→ общество
→ технологии
→ история
→ язык и название
→ визуальная идентичность
→ стиль кораблей
```

## Генератор случайных чисел

Не использовать `Math.random()` внутри генератора.

Использовать собственный PRNG:

```js
function mulberry32(seed) {
  return function random() {
    let t = seed += 0x6D2B79F5;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
```

## Разделить генерацию на независимые потоки

```js
const seeds = {
  profile: hashSeed(seed, "profile"),
  morphology: hashSeed(seed, "morphology"),
  history: hashSeed(seed, "history"),
  visual: hashSeed(seed, "visual"),
  names: hashSeed(seed, "names")
};
```

Это позволит перегенерировать одну часть, не меняя остальные.

# Этап 3. Реализовать правила совместимости

## Задача

## Не использовать только жёсткие запреты

Для большинства сочетаний использовать веса:

```js
const habitatWeights = {
  carbon: {
    ocean: 1.0,
    land: 1.0,
    gasGiantClouds: 0.15,
    asteroid: 0.05,
    stellarCorona: 0.001
  },
  energy: {
    ocean: 0.05,
    land: 0.1,
    gasGiantClouds: 0.8,
    asteroid: 0.3,
    stellarCorona: 1.0
  }
};
```

## Система объяснения редких сочетаний

Когда выбирается маловероятная комбинация, генератор должен добавить причину:

```json
{
  "adaptation": {
    "type": "postbiological_migration",
    "descriptionKey": "ocean_species_uploaded_to_asteroid_network"
  }
}
```

## Примеры зависимостей

* водная жизнь → электрорецепция, эхолокация, биолюминесценция;

* высокая традиционность → древние ритуалы и консервативные формы;

# Рекомендуемая первая практическая задача

Начать следует не с нейросети, а с формирования стабильного набора данных:

```text
alien-civilization/v1
```

После этого реализовать функцию:

```js
function generateCivilization(seed, locks = {}) {
  return {
    profile: generateProfile(seed, locks),
    loreFacts: generateLoreFacts(seed, locks),
    visualIdentity: generateVisualIdentity(seed, locks),
    shipStyle: generateShipStyle(seed, locks)
  };
}
```

Только когда JSON, совместимость и Canvas-аватар работают стабильно, имеет смысл подключать локальную LLM и собирать датасет для специализированной модели изображения.
