# FEATUES — карта функций проекта

Имя файла сохранено в написании из задания. Статусы: **готово**, **частично**, **не сделано**, **к обсуждению**.

## Мир и навигация

| Функция | Статус | Примечание |
|---|---|---|
| Процедурные кластеры, галактики, системы и тела | Готово | Детерминированные генераторы находятся в `src/gen/`. |
| Поверхность планеты и посадка | Готово | Есть отдельная сцена и renderer поверхности. |
| Скрытая информация и исследование | Частично | Игровые данные и зонды есть; PCOS scanner не полностью управляем. |
| Карты, каталог и поиск объектов | Частично | Реализованы intel-модели; полнота пользовательского цикла требует ручного аудита. |
| Пассажирские рейсы без корабля | Не сделано | Зафиксировано как B12. |

## Корабль и оборудование

| Функция | Статус | Примечание |
|---|---|---|
| Корпуса, слоты, масса и оборудование | Готово | Покрыто equipment/hulls тестами. |
| Двигатели и манёвры | Готово | Есть propulsion/maneuver/physics. |
| Оружие и повреждения систем | Готово | Покрыто weapons/system-hit/NPC combat. |
| Реактор и энергетическая сеть | Частично | Концепция и отдельные параметры есть, законченный игровой цикл не подтверждён. |
| Экипаж | Частично | Есть связанные планы и сущности, эксплуатационный цикл не завершён. |

## Экономика и NPC

| Функция | Статус | Примечание |
|---|---|---|
| Торговля, рынки и станции | Готово | Есть economy/stations/trade и тесты. |
| Контракты и события | Готово | Базовые системы реализованы. |
| NPC-агенты и NPC-экономика | Готово/частично | Базовая логика тестируется; сложные долгосрочные стратегии ещё развиваются. |
| Добыча и ресурсы | Частично | Добыча существует, полный цикл переработки и крафта не замкнут. |
| Производственные комплексы | Не сделано | Долгосрочный план. |

## Бортовой компьютер и PCOS

| Функция | Статус | Примечание |
|---|---|---|
| Модульные CPU/RAM/GPU/DRIVE | Готово | Ограничения оборудования применяются runtime. |
| BIOS и выбор загрузочного диска | Готово | Покрыто BIOS тестами. |
| PCVM protected mode v3 | Готово | 134 фиксированных opcode, память, fault/IVT/syscall. |
| PCFS/VFS, пользователи и права | Готово/частично | Основные операции тестируются; rename имеет пробел покрытия. |
| Kernel/init/processes/shell | Готово/частично | Основной boot path подтверждён; отдельные утилиты ещё имеют дефекты. |
| Unix-подобные утилиты | Частично | Большинство бинарников собирается, `make` нестабилен. |
| Графические программы PCOS | Частично | Примитивы работают; scanner выявил проблему end-to-end ввода. |

## Инструменты разработки внутри мира

| Функция | Статус | Примечание |
|---|---|---|
| Host assembler/linker | Готово | PCOB v2 и PCVM binary. |
| Self-hosted assembler/linker | Готово | Bootstrap второго поколения тестируется. |
| C compiler | Частично | Реальное подмножество языка, не полный C89. |
| libc | Частично | Строки/IO/printf/malloc/getopt есть; crt0 status test падает. |
| make | Частично | Hello собирается, сложные рецепты и системный Makefile ломаются. |
| Program Lab | Частично | Отдельная тестовая страница присутствовала в прошлых итерациях, но не является заменой реального запуска PCOS. |

## Контент и представление

| Функция | Статус | Примечание |
|---|---|---|
| RU/EN локализация | Готово | Есть автоматическая проверка литералов сцен. |
